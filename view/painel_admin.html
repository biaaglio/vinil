Acesso exclusivo Admin

Atenção às dependências antes de excluir registros:

• Artistas: possuem álbuns vinculados. Para deletar um artista, é necessário deletar todos os álbuns dele antes.
• Álbuns: possuem músicas/faixas vinculadas. Para deletar um álbum, é necessário deletar todas as faixas dele antes.
• Músicas/Faixas: não possuem dependências e podem ser deletadas diretamente.
